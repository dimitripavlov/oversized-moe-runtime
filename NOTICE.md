# Notices and Attribution

## Oversized MoE Runtime

Oversized MoE Runtime is an independent project derived from
[llama.cpp](https://github.com/ggml-org/llama.cpp).

It is not an official ggml-org project and is not affiliated with,
sponsored by, or endorsed by ggml-org or the llama.cpp maintainers.

The project adds product-specific functionality for running supported
sparse Mixture-of-Experts GGUF models when the total model size exceeds
available physical RAM.
